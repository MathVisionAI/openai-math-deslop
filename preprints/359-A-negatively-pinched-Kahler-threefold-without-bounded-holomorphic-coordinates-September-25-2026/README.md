# A negatively pinched Kähler threefold without bounded holomorphic coordinates

Result 359 · Negative Kähler curvature without bounded holomorphic coordinates

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/f5b72836-7956-4508-8fae-ba61a98bf577) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-negatively-pinched-Kahler-threefold-without-bounded-holomorphic-coordinates-September-25-2026/paper.pdf)

We construct a contractible domain in complex dimension three with a complete Kähler metric whose real sectional curvatures lie between two finite negative constants. It admits no bounded holomorphic map to ℂ<sup>3</sup> with nowhere-vanishing Jacobian and is therefore not biholomorphic to a bounded domain. This gives a negative answer to the negatively pinched Kähler uniformization question.
