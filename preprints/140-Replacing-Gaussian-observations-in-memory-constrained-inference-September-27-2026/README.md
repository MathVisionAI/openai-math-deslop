# Replacing Gaussian observations in memory-constrained inference

Result 140 · Memory–sample lower bounds for noiseless Gaussian regression

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/bbdde3c9-8133-4d3a-8e35-259240972aaf) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Replacing-Gaussian-observations-in-memory-constrained-inference-September-27-2026/paper.pdf)

Replacing the Gaussian rows used to select a finite message by independent rows increases the remaining conditional information by at most $`Cd`$, for a uniform spherical signal, message entropy at most <i>d</i><sup>2</sup>, and the specified row dimensions proportional to <i>d</i>. As an application, we prove that learners with $`M=o(d^2)`$ persistent bits need $`T=\Omega(d\log(1/\epsilon))`$ exact observations to attain uniform-sphere angular success at least 3/5, for $`0\lt \epsilon\le1/10`$ and a deterministic finite horizon.
