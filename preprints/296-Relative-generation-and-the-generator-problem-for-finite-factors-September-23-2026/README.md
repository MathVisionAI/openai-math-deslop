# Relative generation and the generator problem for finite factors

Result 296 · The generator problem for finite factors

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/4da9fa2f-d3bb-4b74-8a03-badca4d70962) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Relative-generation-and-the-generator-problem-for-finite-factors-September-23-2026/paper.pdf)

We prove that every type II<sub>1</sub> factor with separable predual is generated by one operator, equivalently by two self-adjoint operators. Combined with the established direct-integral reduction to this case, this gives an affirmative solution of the generator problem for von Neumann algebras with separable predual.
