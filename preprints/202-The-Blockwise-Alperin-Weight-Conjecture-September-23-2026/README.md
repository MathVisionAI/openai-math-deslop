# The Blockwise Alperin Weight Conjecture

Result 202 · The blockwise Alperin weight conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e00a2fc0-518a-420f-a497-0572427fa994) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-Blockwise-Alperin-Weight-Conjecture-September-23-2026/paper.pdf)

We prove the numerical blockwise Alperin weight conjecture for every finite group and every prime <i>p</i>. For each <i>p</i>-block <i>B</i>, the number of irreducible Brauer characters in <i>B</i> equals the number of conjugacy classes of <i>B</i>-weights.
