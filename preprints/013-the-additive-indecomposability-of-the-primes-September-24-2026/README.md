# The additive indecomposability of the primes

Result 013 · Ostmann’s inverse Goldbach conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/226aabce-b5b6-4d8e-9f16-060a366afdee) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/the-additive-indecomposability-of-the-primes-September-24-2026/paper.pdf)

We prove Ostmann's inverse Goldbach conjecture: no set differing from the primes by finitely many elements can be written as $`A+B`$, where <i>A</i> and <i>B</i> are sets of nonnegative integers with at least two elements each.
