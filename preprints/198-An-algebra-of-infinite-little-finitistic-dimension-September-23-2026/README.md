# An algebra of infinite little finitistic dimension

Result 198 · A counterexample to finitistic-dimension finiteness

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/2556f69a-7b99-4558-a846-c3babc6f8c46) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/An-algebra-of-infinite-little-finitistic-dimension-September-23-2026/paper.pdf)

We construct a finite-dimensional complex algebra whose finite-dimensional modules have unbounded finite projective dimensions. This disproves the little finitistic-dimension conjecture.
