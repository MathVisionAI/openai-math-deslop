# Fourfold nonvanishing by minimal metrics and moving jets

Result 034 · Log abundance for compact Kähler spaces under logarithmic Iitaka subadditivity

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/a7d30d92-7e9b-450f-b56e-0e351a027e4c) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Fourfold-nonvanishing-by-minimal-metrics-and-moving-jets-September-27-2026/paper.pdf)

We prove canonical nonvanishing for smooth connected projective complex fourfolds: if <i>K</i><sub><i>X</i></sub> is pseudo-effective, then $`H^0(X,mK_X)\ne0`$ for some positive integer <i>m</i>.
