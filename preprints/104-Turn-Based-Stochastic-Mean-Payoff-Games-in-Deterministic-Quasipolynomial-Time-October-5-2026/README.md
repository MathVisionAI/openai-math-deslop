# Turn-Based Stochastic Mean-Payoff Games in Deterministic Quasipolynomial Time

Result 104 · Quasipolynomial algorithms for mean-payoff, stochastic and parity games

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/2fdc82d5-6964-40fe-870b-b6006483d5ba) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Turn-Based-Stochastic-Mean-Payoff-Games-in-Deterministic-Quasipolynomial-Time-October-5-2026/stochastic-mean-payoff-games.pdf)

We give a uniform deterministic quasipolynomial-time algorithm for finite turn-based stochastic mean-payoff games with signed integer rewards and rational chance-transition probabilities encoded in binary. It computes exactly the vertices of nonnegative value, including value zero, for the expectation of the pathwise liminf mean payoff. The algorithm uses exact rational arithmetic and $`2^{O((\log(L+2))^2)}`$ bit operations, where <i>L</i> is the complete binary input length.
