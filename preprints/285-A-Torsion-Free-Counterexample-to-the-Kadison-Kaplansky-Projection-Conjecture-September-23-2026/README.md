# A torsion-free counterexample to the Kadison–Kaplansky projection conjecture

Result 285 · Counterexamples to Baum–Connes and Kadison–Kaplansky

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/96b76203-ba51-4831-9eb4-5623f2dd90ee) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Torsion-Free-Counterexample-to-the-Kadison-Kaplansky-Projection-Conjecture-September-23-2026/paper.pdf)

We construct a finitely generated torsion-free discrete group whose reduced group <i>C</i><sup>∗</sup>-algebra contains a projection other than zero and the identity. This disproves the Kadison–Kaplansky projection conjecture.
