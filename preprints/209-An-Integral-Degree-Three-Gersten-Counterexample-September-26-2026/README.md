# An integral degree-three Gersten counterexample

Result 209 · Integral counterexamples to Gersten’s conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/b877de5c-fa1c-438a-96c1-203e7a05968a) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/An-Integral-Degree-Three-Gersten-Counterexample-September-26-2026/paper.pdf)

We construct a two-dimensional ramified regular local ring <i>A</i> in mixed characteristic $`(0,5)`$ for which the integral map $`K_3(A)\to K_3(\mathop{\mathrm{Frac}}\nolimits A)`$ has nonzero kernel. This gives a negative answer to the unrestricted integral Gersten conjecture.
