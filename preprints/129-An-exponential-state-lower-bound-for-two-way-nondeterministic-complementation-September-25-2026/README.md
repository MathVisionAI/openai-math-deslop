# An exponential state lower bound for two-way nondeterministic complementation

Result 129 · Exponential state costs for two-way automata

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e4821b3b-c6cc-47f4-89de-475babc7425c) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/An-exponential-state-lower-bound-for-two-way-nondeterministic-complementation-September-25-2026/paper.pdf)

We prove that two-way nondeterministic finite automata cannot be complemented with a polynomial number of states independent of the alphabet. For each <i>n</i> ≥ 4 we construct an <i>n</i>-state automaton over a finite alphabet whose complement requires at least $`\tfrac12 2^{\lfloor(n-4)/127\rfloor}-1`$ states.
