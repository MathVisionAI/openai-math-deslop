# An irrational-trace counterexample to reduced Baum–Connes

Result 285 · Counterexamples to Baum–Connes and Kadison–Kaplansky

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/90c5d118-cd3b-4cd9-b865-cd4421fd2347) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/An-Irrational-Trace-Counterexample-to-Reduced-Baum-Connes-September-23-2026/paper.pdf)

We construct a finitely generated discrete group whose reduced group <i>C</i><sup>∗</sup>-algebra contains a projection of irrational canonical trace. Its <i>K</i><sub>0</sub>-class lies outside the image of the coefficient-free reduced Baum–Connes assembly map. This disproves the coefficient-free reduced Baum–Connes conjecture for countable discrete groups.
