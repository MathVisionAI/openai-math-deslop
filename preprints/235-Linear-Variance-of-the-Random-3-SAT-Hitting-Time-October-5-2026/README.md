# Linear Variance of the Random 3-SAT Hitting Time

Result 235 · Limiting random SAT thresholds, sharp variance and computability

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/6aedd378-6f78-421d-8c95-b4ecab44045c) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Linear-Variance-of-the-Random-3-SAT-Hitting-Time-October-5-2026/linear-variance-of-the-random-3-sat-hitting-time.pdf)

For random 3-SAT on <i>n</i> Boolean variables, with independent uniformly signed clauses on three distinct variables sampled with replacement, we prove that the first unsatisfiable prefix has variance $`\Theta(n)`$. The upper bound removes the logarithmic loss in the earlier variance estimate; the matching lower bound follows from Wilson's transition-width theorem.
