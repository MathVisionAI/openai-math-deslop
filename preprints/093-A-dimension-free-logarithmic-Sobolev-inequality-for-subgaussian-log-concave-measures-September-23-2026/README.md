# A dimension-free logarithmic Sobolev inequality for subgaussian log-concave measures

Result 093 · Dimension-free logarithmic Sobolev inequality for subgaussian log-concave measures

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/7b93fed3-4572-4f36-96af-cf04f666a3b8) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-dimension-free-logarithmic-Sobolev-inequality-for-subgaussian-log-concave-measures-September-23-2026/paper.pdf)

We prove that every centered log-concave probability measure with a Lebesgue density on ℝ<sup><i>n</i></sup> and linear subgaussian parameter <i>a</i> satisfies $`\mathop{\mathrm{Ent}}\nolimits _\mu(f^2)\le Ca^2\int|Df|^2\,d\mu`$ for compactly supported smooth <i>f</i>, with one universal constant <i>C</i>. This resolves positively the dimension-free logarithmic Sobolev conjecture for subgaussian log-concave measures.
