# A universal group of type F∞

Result 250 · Boone–Higman embeddings with higher finiteness

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/16770e1b-733d-48a0-a26f-439e9e441870) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-universal-group-of-type-F-infinity-September-23-2026/paper.pdf)

We construct a single group of type <i>F</i><sub>∞</sub> containing every finitely presented group. Its finitely generated subgroups, up to isomorphism, are exactly the finitely generated recursively presented groups. This answers the <i>F</i><sub>∞</sub> form of the higher-dimensional Higman embedding question.
