# Every four-dimensional Kakeya set has full Hausdorff dimension

Result 074 · Kakeya in three and four dimensions

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/a33c6f5d-ce01-41ac-87ec-dd4be5e3eeb5) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Every-four-dimensional-Kakeya-set-has-full-Hausdorff-dimension-September-24-2026/paper.pdf)

We prove the four-dimensional Hausdorff-dimension Kakeya conjecture: every subset of ℝ<sup>4</sup> containing a unit line segment in every direction has Hausdorff dimension four. No compactness or regularity assumption is imposed on the set or its witnessing line family.
