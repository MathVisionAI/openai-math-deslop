# Bi-Lipschitz Absorption of c0 Without a Linear Copy of c0

Result 324 · Lipschitz equivalent Banach spaces need not be linearly isomorphic

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/a59669d9-a051-4feb-9966-816f0789d633) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Bi-Lipschitz-Absorption-of-c0-Without-a-Linear-Copy-of-c0-September-26-2026/paper.pdf)

We construct a separable real Banach space <i>Z</i> that contains no linear copy of <i>c</i><sub>0</sub>, yet is bi-Lipschitz equivalent to $`Z\oplus_\infty c_0`$. The same space contains a bi-Lipschitz image of every separable metric space.
