# L1 Embeddings of Graphs of Bounded Treewidth

Result 089 · Bounded-distortion <i>L</i><sub>1</sub> embeddings of planar and bounded-treewidth graphs

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/2c30ca6c-9a94-46a9-bb35-15b8c5a5540f) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/L1-Embeddings-of-Graphs-of-Bounded-Treewidth-September-23-2026/paper.pdf)

For every fixed treewidth bound, the shortest-path metrics of finite connected graphs with arbitrary positive real edge lengths embed into real <i>L</i><sub>1</sub> with uniformly bounded distortion. This resolves the bounded-treewidth case of the Gupta–Newman–Rabinovich–Sinclair conjecture positively.
