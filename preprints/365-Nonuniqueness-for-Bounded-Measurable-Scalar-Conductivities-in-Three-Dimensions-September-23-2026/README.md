# Nonuniqueness for bounded measurable scalar conductivities in three dimensions

Result 365 · Joint metric and connection recovery from one boundary patch

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/f027b143-75c7-4feb-ae5e-143051b1a4b6) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Nonuniqueness-for-Bounded-Measurable-Scalar-Conductivities-in-Three-Dimensions-September-23-2026/paper.pdf)

We construct two distinct uniformly positive bounded measurable scalar conductivities on a ball in ℝ<sup>3</sup> with the same full Dirichlet-to-Neumann operator. Both conductivities equal one near the boundary. This gives nonuniqueness in the scalar Calderón problem at bounded measurable regularity.
