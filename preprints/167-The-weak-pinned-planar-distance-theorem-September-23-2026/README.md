# The weak pinned planar distance theorem

Result 167 · Planar distinct distances and unit-distance bounds

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/d96ea8f6-c5f1-4721-8d38-92b4e04c33fd) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-weak-pinned-planar-distance-theorem-September-23-2026/paper.pdf)

We prove the weak pinned Erdős distinct-distance conjecture. For every fixed <i>ε</i> &gt; 0, all but $`o(n)`$ points of any <i>n</i>-point planar set determine at least $`n^{1-\varepsilon}`$ distinct nonzero distances.
