# A linear cycle-and-edge decomposition of every graph

Result 181 · The Erdős–Gallai cycle-decomposition conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/0965ebaa-4555-492e-a0be-a6639565bbb1) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-linear-cycle-and-edge-decomposition-of-every-graph-September-24-2026/main.pdf)

We prove that every finite simple undirected graph on <i>n</i> vertices has an edge partition into at most $`Cn`$ simple cycles and single edges, for an absolute constant <i>C</i>. This resolves the Erdős–Gallai cycle decomposition conjecture positively.
