# Choiceless polynomial time with counting does not capture polynomial time

Result 243 · Separating choiceless counting from polynomial time and witnessed choice

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/aa7569f9-584a-4d01-b557-fce71c6d6b23) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Choiceless-polynomial-time-with-counting-does-not-capture-polynomial-time-September-23-2026/paper.pdf)

We prove that choiceless polynomial time with counting does not capture polynomial time on unordered finite structures, confirming the noncapture conjecture of Blass, Gurevich and Shelah. A linear-consistency query over 𝔽<sub>3</sub> in a fixed binary vocabulary is decidable in polynomial time but not in the full counting formalism.
