# The strong thin tree conjecture

Result 174 · Deterministic construction of strong thin spanning trees

Reading Mode version not yet available · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-strong-thin-tree-conjecture-September-23-2026/paper.pdf)

We prove that every finite loopless <i>k</i>-edge-connected multigraph on at least two vertices, with <i>k</i> ≥ 1, has a spanning tree meeting each cut in at most $`C/k`$ times the size of the cut, where <i>C</i> is a universal constant. This resolves the strong thin tree conjecture.
