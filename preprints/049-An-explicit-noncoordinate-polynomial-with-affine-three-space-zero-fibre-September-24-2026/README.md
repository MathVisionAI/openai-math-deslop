# An explicit noncoordinate polynomial with affine three-space zero fibre

Result 049 · A stable-coordinate counterexample in four variables

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/2655c2e0-3db6-463a-b7d5-6214b7f17bd3) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/An-explicit-noncoordinate-polynomial-with-affine-three-space-zero-fibre-September-24-2026/paper.pdf)

We construct an explicit counterexample to the Abhyankar–Sathaye conjecture: a noncoordinate polynomial in four complex variables whose zero fibre is affine three-space. Adjoining variables gives counterexamples in every ambient dimension at least four.
