# Filtered chromatic splitting at generic primes

Result 318 · Chromatic splitting: filtrations and counterexamples

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/fee1850c-8461-4b44-a6b0-7b0a460637ff) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Filtered-chromatic-splitting-at-generic-primes-September-25-2026/paper.pdf)

For every <i>n</i> ≥ 1 and prime $`p\gt n+1`$, we construct a $`2^n`$-stage ordered filtration of $`L_{n-1}L_{K(n)}S_p^\wedge`$ with the classical chromatic-splitting cofibers. The map from the first stage to the target is the canonical localization unit.
