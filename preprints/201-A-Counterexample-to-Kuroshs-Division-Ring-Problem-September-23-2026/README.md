# A Counterexample to Kurosh’s Division-Ring Problem

Result 201 · A counterexample to Kurosh’s division-ring problem

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/693d8c86-f7aa-4829-96a5-dfff473d3c8e) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Counterexample-to-Kuroshs-Division-Ring-Problem-September-23-2026/paper.pdf)

We construct a countable division ring of characteristic zero that is algebraic over its center, generated by two elements as an algebra over that center, and infinite-dimensional over it. This gives a negative answer to the Kurosh problem for division rings.
