# An explicit obstruction to nuclear norm-ultrapower embeddings

Result 292 · Kirchberg's $`\mathcal O_2`$ norm-ultrapower embedding problem

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/58958cda-5031-41b4-9a40-839f51a4b378) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/An-explicit-obstruction-to-nuclear-norm-ultrapower-embeddings-September-23-2026/paper.pdf)

We give a negative answer to Kirchberg's norm-ultrapower embedding problem. We construct an explicit separable unital full group <i>C</i><sup>∗</sup>-algebra that admits no unital embedding into <i>B</i><sup><i>ω</i></sup>, for any nonzero unital nuclear <i>C</i><sup>∗</sup>-algebra <i>B</i> and any free ultrafilter <i>ω</i> on ℕ. In particular, it does not embed unitally into $`\mathcal O_2^\omega`$.
