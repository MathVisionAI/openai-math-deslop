# GOE bulk universality for fixed-degree random regular graphs

Result 219 · GOE bulk universality for regular graphs with weak Anderson disorder

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/f3533c58-8206-4cc3-9c94-a67b7194eba9) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/GOE-bulk-universality-for-fixed-degree-random-regular-graphs-September-23-2026/paper.pdf)

We prove the fixed-degree bulk-universality conjecture for random regular graphs. For every fixed integer <i>d</i> ≥ 3 and every fixed energy in the open Kesten–McKay bulk, the unfolded eigenvalue point process of the adjacency matrix of a uniform simple labelled <i>d</i>-regular graph converges to the GOE bulk process. The convergence holds along all admissible graph sizes, without additional conditioning.
