# Every complex K3 surface is Oka

Result 042 · Oka classification for minimal compact complex surfaces: Kodaira dimension zero and class VII

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/d534dc8f-b0af-4201-ba17-862df99a69f0) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Every-complex-K3-surface-is-Oka-September-23-2026/paper.pdf)

We prove that every complex K3 surface <i>X</i> is Oka, resolving the K3 Oka conjecture. Equivalently, for every <i>m</i> ≥ 1, every holomorphic map to <i>X</i> from a neighborhood of a compact convex set in ℂ<sup><i>m</i></sup> can be approximated uniformly on that set by entire maps $`\mathbb C^m\to X`$.
