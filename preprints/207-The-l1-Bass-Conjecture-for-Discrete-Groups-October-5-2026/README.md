# The ℓ¹-Bass Conjecture for Discrete Groups

Result 207 · The ℓ¹-Bass conjecture for all discrete groups

We prove the <i>ℓ</i><sup>1</sup>-Bass conjecture for every discrete group. The Hattori–Stallings trace of every idempotent matrix over the complex <i>ℓ</i><sup>1</sup> group algebra is supported on finitely many conjugacy classes of finite-order elements.
