# The approximation threshold for metric k-median

Result 125 · The metric <i>k</i>-median approximation threshold and recovery

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e3c6d1fc-66df-49b3-8dea-fd5e8fc05074) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-Approximation-Threshold-for-Metric-k-Median-September-24-2026/main.pdf)

For every fixed <i>ε</i> &gt; 0, we give a deterministic polynomial-time $`(1+2/e+\varepsilon)`$-approximation for finite rational metric <i>k</i>-median with specified candidate facilities, opening at most <i>k</i> facilities. Under $`P\ne NP`$, the infimum approximation factor in this model is therefore $`1+2/e`$.
