# Balanced counterexamples to Ryser's conjecture at prime orders

Result 162 · Counterexamples to Ryser’s covering conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/541c01a3-50fa-4860-8d83-67508adbe299) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Balanced-Counterexamples-to-Rysers-Conjecture-at-Prime-Orders-September-27-2026/paper.pdf)

For every sufficiently large prime <i>q</i>, we construct a finite intersecting $`(q+1)`$-partite $`(q+1)`$-uniform hypergraph with covering number $`q+1`$ and exactly $`q+1`$ nonisolated vertices in each part. This disproves Ryser's covering conjecture, even for intersecting hypergraphs with equally sized parts.
