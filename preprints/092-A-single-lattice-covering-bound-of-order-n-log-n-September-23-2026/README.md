# A single-lattice covering bound of order n log n

Result 092 · The optimal order of convex-body covering density

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/8d8c8b24-eeb5-4fe5-8b4d-123402b96ec2) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-single-lattice-covering-bound-of-order-n-log-n-September-23-2026/paper.pdf)

Every convex body in ℝ<sup><i>n</i></sup>, <i>n</i> ≥ 2, admits a covering by translates along one full-rank lattice with density at most $`Cn\log n`$, for an absolute constant <i>C</i>. No symmetry or boundary regularity is assumed.
