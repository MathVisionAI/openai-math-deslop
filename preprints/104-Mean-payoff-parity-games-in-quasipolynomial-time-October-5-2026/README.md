# Mean-payoff parity games in quasipolynomial time

Result 104 · Quasipolynomial algorithms for mean-payoff, stochastic and parity games

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e66037ef-8b17-4d8e-9a10-8466ec34f968) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Mean-payoff-parity-games-in-quasipolynomial-time-October-5-2026/mean-payoff-parity.pdf)

We give a uniform deterministic quasipolynomial-time algorithm for mean-payoff parity games. It computes all vertices from which a player can enforce both nonnegative liminf mean payoff and the parity condition, with arbitrary signed binary rewards and unrestricted binary priorities. The running time is $`2^{O((\log(L+2))^2)}`$ bit operations, where <i>L</i> is the complete input length.
