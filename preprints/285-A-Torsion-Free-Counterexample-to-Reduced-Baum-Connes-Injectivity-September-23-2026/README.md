# A torsion-free counterexample to reduced Baum–Connes injectivity

Result 285 · Counterexamples to Baum–Connes and Kadison–Kaplansky

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/6628d7aa-32a7-41ec-86b3-0941ca68bf55) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Torsion-Free-Counterexample-to-Reduced-Baum-Connes-Injectivity-September-23-2026/paper.pdf)

We disprove rational injectivity of the coefficient-free reduced Baum–Connes assembly map for torsion-free groups. Specifically, we construct a finitely generated torsion-free discrete group whose degree-zero assembly map has a kernel class of infinite order.
