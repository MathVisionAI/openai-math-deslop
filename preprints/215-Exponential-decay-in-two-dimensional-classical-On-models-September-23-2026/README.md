# Exponential decay in two-dimensional classical O(n) models

Result 215 · Canonical $`O(3)`$ continuum limit and exact $`O(4)`$ mass asymptotics

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/ceca929f-10dc-406d-abf1-cb6925d2bf6d) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Exponential-decay-in-two-dimensional-classical-On-models-September-23-2026/paper.pdf)

We prove exponential decay of two-point correlations for the classical nearest-neighbor $`O(n)`$ model on the square lattice, for every <i>n</i> ≥ 3 and every finite positive inverse temperature. The estimate is uniform over finite free-boundary subgraphs and bounded nonnegative edge strengths. This resolves positively the all-temperature exponential spin-decay conjecture for these models.
