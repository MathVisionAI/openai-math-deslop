# The Falconer distance conjecture in all dimensions

Result 073 · The Falconer distance conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/21768d2b-9022-4181-8c3b-98a6ca5d1c2b) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-Falconer-distance-conjecture-in-all-dimensions-September-23-2026/paper.pdf)

We resolve the Falconer distance conjecture in every dimension. For every integer <i>d</i> ≥ 2, a compact subset of ℝ<sup><i>d</i></sup> with Hausdorff dimension greater than $`d/2`$ determines a set of Euclidean distances of positive Lebesgue measure.
