# A finite-time singularity of Calabi flow on projective space

Result 352 · A finite-time singularity of Calabi flow

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/51ace3d3-ab72-45ef-acbf-d1803f7aae09) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-finite-time-singularity-of-Calabi-flow-on-projective-space-September-24-2026/paper.pdf)

We construct a smooth Kähler metric in the Fubini–Study class of $`\mathbb{CP}^{10}`$ whose Calabi flow develops unbounded scalar curvature in finite time. This disproves Chen's smooth long-time existence conjecture, even in a class containing a constant-scalar-curvature metric.
