# Sharp nodal length on smooth surfaces

Result 350 · Yau’s nodal bounds: surfaces and higher dimensions

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/02996f18-0274-4c3a-9220-a3d0927c49f1) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Sharp-nodal-length-on-smooth-surfaces-September-23-2026/paper.pdf)

We prove that a nonzero real Laplace eigenfunction with eigenvalue <i>λ</i> &gt; 0 on a fixed smooth closed connected Riemannian surface has nodal length at most $`C\sqrt\lambda`$. Together with the known lower bound, this proves Yau's conjecture in this setting.
