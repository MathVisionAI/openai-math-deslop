# A Sharp Threshold Bound for Monotone Graph Properties

Result 186 · Uniform influence and sharp thresholds for graph and hypergraph properties

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/9854422e-1ab1-4157-8155-b388510c9228) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Sharp-Threshold-Bound-for-Monotone-Graph-Properties-September-25-2026/paper.pdf)

We prove the Friedgut–Kalai sharp-threshold conjecture. For every integer <i>n</i> ≥ 2, every nontrivial increasing family of graphs on <i>n</i> vertices invariant under all vertex permutations, and every $`0\lt \varepsilon\lt 1/2`$, the edge probabilities at which its probability equals <i>ε</i> and $`1-\varepsilon`$ differ by at most $`C\log(1/(2\varepsilon))/(\log n)^2`$, for a universal constant <i>C</i>.
