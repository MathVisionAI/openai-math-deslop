# Universal Tensor Squares for Symmetric Groups

Result 205 · Saxl’s conjecture and universal tensor squares

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/0c256ed7-b22a-4f1e-a74c-78e90356eec1) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Universal-Tensor-Squares-for-Symmetric-Groups-September-24-2026/main.pdf)

For every positive integer <i>n</i> other than 2, 4, and 9, we prove that some irreducible complex representation of <i>S</i><sub><i>n</i></sub> has a tensor square containing every irreducible representation. This resolves the tensor square conjecture for symmetric groups affirmatively.
