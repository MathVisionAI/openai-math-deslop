# A power saving for planar unit distances

Result 167 · Planar distinct distances and unit-distance bounds

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/cbf5ba47-6484-404f-8dc0-cf0ccd747c1a) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-power-saving-for-planar-unit-distances-September-23-2026/paper.pdf)

We prove a power saving for the planar unit-distance problem: for some absolute $`\beta\lt 4/3`$, every set of <i>n</i> points in the Euclidean plane determines $`O(n^\beta)`$ unordered pairs at unit distance.
