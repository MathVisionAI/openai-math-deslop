# Quantitative Near-Kerr Evolution and Generic C2 Future Inextendibility

Result 264 · Strong cosmic censorship near two-ended Kerr data

For every fixed rotating subextremal Kerr bridge, we prove that smooth vacuum data admitting a <i>C</i><sup>2</sup> future extension of their full maximal globally hyperbolic development form a meagre set in a neighborhood defined by one finite-order seminorm. The topology allows arbitrary symbol-bounded asymptotically flat tails and imposes no symmetry.
