# Counterexamples to the duality conjecture for metric entropy

Result 329 · A counterexample to metric-entropy duality

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/9e741e30-3487-44ce-ae75-fd61de8a2508) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Counterexamples-to-the-duality-conjecture-for-metric-entropy-September-24-2026/main.pdf)

We disprove Pietsch's dimension-free duality conjecture for metric entropy. For every proposed pair of universal constants, we construct origin-symmetric convex bodies that violate the corresponding covering-entropy inequality, already when the covering body is a cube.
