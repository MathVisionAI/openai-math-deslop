# A counterexample to the nearby Lagrangian conjecture

Result 340 · A counterexample to the nearby Lagrangian conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e0ed6466-f768-42b6-879f-c810b1290cd9) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-counterexample-to-the-nearby-Lagrangian-conjecture-September-23-2026/paper.pdf)

We disprove the unrestricted nearby Lagrangian conjecture. For some sufficiently large even integer <i>N</i>, we construct a closed exact smoothly embedded Lagrangian in $`T^*(S^9\times S^{N-1})`$ that is diffeomorphic to the base but is not Hamiltonian isotopic to the zero section.
