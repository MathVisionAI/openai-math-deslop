# Generic C1 Future Inextendibility Near Rotating Subextremal Kerr Spacetimes

Result 264 · Strong cosmic censorship near two-ended Kerr data

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/7aa85dd8-bfa7-491c-a802-2a8079bbcf80) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Generic-C1-Future-Inextendibility-Near-Rotating-Subextremal-Kerr-Spacetimes-September-23-2026/paper.pdf)

For each fixed Kerr spacetime with mass <i>M</i> &gt; 0 and rotation $`0\lt \mathfrak a\lt M`$, we prove that a dense <i>G</i><sub><i>δ</i></sub> set of nearby smooth, complete two-ended vacuum data has a maximal globally hyperbolic development with no future <i>C</i><sup>1</sup> extension. The neighborhood and genericity are defined in a weighted smooth topology, and ambient extensions may be nonvacuum.
