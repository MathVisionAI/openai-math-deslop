# Prime Predecessors with an Even Number of Prime Factors

Result 011 · Prime-factor statistics of $`p-1`$

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/0a24565c-8e58-4b41-aded-ee5ec4f8d587) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Prime-Predecessors-with-an-Even-Number-of-Prime-Factors-September-17-2026/paper.pdf)

We prove that there are infinitely many primes <i>p</i> for which $`p-1`$ is squarefree and has an even number of prime factors. Equivalently, there are infinitely many primes <i>p</i> with $`\mu(p-1)=1`$.
