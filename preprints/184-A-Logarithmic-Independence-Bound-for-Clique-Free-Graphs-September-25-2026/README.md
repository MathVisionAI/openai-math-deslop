# A logarithmic independence bound for clique-free graphs

Result 184 · Correspondence coloring with a fixed forbidden subgraph

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/9dea2f9c-50bb-446c-9237-e29b94d25de4) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Logarithmic-Independence-Bound-for-Clique-Free-Graphs-September-25-2026/paper.pdf)

For every fixed integer <i>r</i> ≥ 4, every <i>K</i><sub><i>r</i></sub>-free graph on <i>n</i> vertices with average degree <i>d</i> ≥ 2 has an independent set of size at least $`c_r n\log d/d`$, where $`c_r\gt 0`$ depends only on <i>r</i>. This proves the fixed-clique-size independence conjecture of Ajtai, Erdős, Komlós and Szemerédi.
