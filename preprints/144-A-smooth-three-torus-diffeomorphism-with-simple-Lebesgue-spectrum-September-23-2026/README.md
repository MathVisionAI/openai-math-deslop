# A smooth three-torus diffeomorphism with simple Lebesgue spectrum

Result 144 · Banach’s simple Lebesgue-spectrum problem

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/a841c6d7-fac4-42ac-a182-32ead56e2b0f) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-smooth-three-torus-diffeomorphism-with-simple-Lebesgue-spectrum-September-23-2026/paper.pdf)

We solve the probability-preserving form of Banach's simple Lebesgue-spectrum problem in smooth dynamics. We construct a <i>C</i><sup>∞</sup> diffeomorphism of the three-torus that preserves standard volume and whose Koopman operator has simple Lebesgue spectrum on the entire mean-zero <i>L</i><sup>2</sup> space.
