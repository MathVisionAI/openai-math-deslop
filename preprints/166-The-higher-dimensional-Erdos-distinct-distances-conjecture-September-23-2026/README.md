# The higher-dimensional Erdős distinct-distances conjecture

Result 166 · The higher-dimensional Erdős distinct-distances conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/6befb325-91cc-4a0c-9b1f-92cac0bfb6f9) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-higher-dimensional-Erdos-distinct-distances-conjecture-September-23-2026/paper.pdf)

For every fixed integer <i>d</i> ≥ 3, we prove that every set of <i>n</i> ≥ 2 distinct points in ℝ<sup><i>d</i></sup> determines at least $`c_d n^{2/d}`$ distinct distances, where $`c_d\gt 0`$ depends only on <i>d</i>. This resolves the higher-dimensional Erdős distinct-distances conjecture positively.
