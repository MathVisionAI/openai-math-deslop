# The maximal triangular Hilbert transform at the symmetric point

Result 082 · Annular variation and dyadic absolute bounds for the triangular Hilbert transform

Reading Mode version not yet available · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-maximal-triangular-Hilbert-transform-at-the-symmetric-point-September-24-2026/paper.pdf)

For arbitrary complex inputs in $`L^3(\mathbb R^2)`$, we prove the pointwise maximal $`L^3\times L^3\to L^{3/2}`$ estimate for the triangular Hilbert transform, with the supremum over both hard truncation endpoints. The estimate yields joint almost-everywhere and <i>L</i><sup>3/2</sup> convergence as the lower endpoint tends to zero and the upper endpoint tends to infinity. This also proves the conjectured scalar estimate at the symmetric point.
