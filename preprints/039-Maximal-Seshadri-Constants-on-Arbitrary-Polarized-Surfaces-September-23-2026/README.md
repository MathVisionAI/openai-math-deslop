# Maximal Seshadri constants on arbitrary polarized surfaces

Result 039 · Nagata’s conjecture and maximal Seshadri constants

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/10cc20dc-0fd6-47ea-bd40-801c7e24c3d2) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Maximal-Seshadri-Constants-on-Arbitrary-Polarized-Surfaces-September-23-2026/main.pdf)

We prove that, for every smooth integral complex projective surface <i>S</i> and every ample line bundle <i>L</i>, the multipoint Seshadri constant at <i>r</i> very general points equals $`\sqrt{L^2/r}`$ for every sufficiently large integer <i>r</i>. This resolves positively the qualitative Nagata–Biran conjecture for surfaces.
