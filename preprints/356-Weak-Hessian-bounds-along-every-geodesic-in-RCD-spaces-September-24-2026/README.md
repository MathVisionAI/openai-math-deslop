# Weak Hessian bounds along every geodesic in RCD spaces

Result 356 · Gigli’s characterization of Alexandrov curvature

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e74b9457-1112-41a8-9177-5f804cb72912) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Weak-Hessian-bounds-along-every-geodesic-in-RCD-spaces-September-24-2026/weak-hessian-geodesics.pdf)

On a full-support $`\mathrm{RCD}(K,N)`$ space with $`1\lt N\lt \infty`$, we prove that a bounded globally Lipschitz function whose distributional Hessian is bounded above by a bounded continuous function satisfies the corresponding second-derivative inequality along every minimizing geodesic.
