# Monochromatic finite sums and products in the positive integers

Result 164 · Hindman’s finite sums and products conjecture

Reading Mode version not yet available · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Monochromatic-finite-sums-and-products-in-the-positive-integers-September-23-2026/paper.pdf)

We prove Hindman's finite sums and products conjecture: for every finite coloring of the positive integers and every positive integer <i>k</i>, there is a <i>k</i>-element set whose nonempty subset sums and nonempty subset products all have the same color.
