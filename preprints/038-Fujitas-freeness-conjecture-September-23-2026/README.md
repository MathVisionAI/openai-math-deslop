# Fujita's freeness conjecture

Result 038 · Fujita’s freeness conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/9a2fb8aa-0c41-4712-9088-c02e6854331b) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Fujitas-freeness-conjecture-September-23-2026/Fujitas-freeness-conjecture-September-23-2026.pdf)

We prove Fujita's freeness conjecture. If <i>X</i> is a smooth complex projective variety of dimension <i>n</i> and <i>L</i> is an ample line bundle, then $`K_X+mL`$ is globally generated for every integer $`m\geq n+1`$.
