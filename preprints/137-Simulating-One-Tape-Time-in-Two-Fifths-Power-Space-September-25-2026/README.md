# Simulating One-Tape Time in Two-Fifths-Power Space

Result 137 · One-tape time simulation in two-fifths-power space

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/5f27ce73-429e-4f65-96aa-f86509fdf157) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Simulating-One-Tape-Time-in-Two-Fifths-Power-Space-September-25-2026/article.pdf)

We show that a fixed deterministic Turing machine with one writable tape and head can be simulated in $`O(T^{2/5}\mathop{\mathrm{polylog}}\nolimits (T+2))`$ work-space bits when a binary time cap <i>T</i> ≥ 2 is supplied. The simulator computes the finite-control and halting outcome by time <i>T</i>; its running time is unrestricted. The result allows a fixed number of read-only input heads and requires a fixed accessor that supplies every initial writable and read-only symbol within distance <i>T</i> of the relevant head origin in polylogarithmic space. This improves the square-root space exponent for one-tape machines, answering Williams's question for this model.
