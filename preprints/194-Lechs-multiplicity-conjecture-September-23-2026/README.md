# Lech's multiplicity conjecture

Result 194 · Lech’s multiplicity conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/377aced4-ab5e-4d8c-9411-c2b05573c84d) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Lechs-multiplicity-conjecture-September-23-2026/paper.pdf)

We prove Lech's multiplicity conjecture: Hilbert–Samuel multiplicity cannot decrease under a flat local homomorphism of nonzero Noetherian local rings. The result holds in arbitrary dimension, with no restrictions on the residue fields or characteristics.
