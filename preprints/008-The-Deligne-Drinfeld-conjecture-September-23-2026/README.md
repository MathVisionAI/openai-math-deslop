# The Deligne-Drinfeld conjecture

Result 008 · The Deligne–Drinfeld conjecture

We prove the Deligne–Drinfeld conjecture: the rational Grothendieck–Teichmüller Lie algebra is freely generated by one element in every odd weight at least three, with the corresponding isomorphism after weight completion.
