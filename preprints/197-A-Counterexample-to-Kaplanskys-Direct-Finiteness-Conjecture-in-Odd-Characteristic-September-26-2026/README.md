# A Counterexample to Kaplansky's Direct-Finiteness Conjecture in Odd Characteristic

Result 197 · A torsion-free group algebra that is not directly finite

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/86aa565c-6b63-4b48-8078-e37ab2764be7) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Counterexample-to-Kaplanskys-Direct-Finiteness-Conjecture-in-Odd-Characteristic-September-26-2026/paper.pdf)

We construct a counterexample to Kaplansky's direct-finiteness conjecture in odd characteristic. For one specified odd prime <i>p</i>, we obtain a field <i>K</i> of order <i>p</i><sup>4</sup>, a finitely generated group <i>G</i> containing torsion, and finite sums $`a,b\in K[G]`$ with $`ab=1`$ but $`ba\ne1`$. The same elements define a cellular automaton on <i>K</i><sup><i>G</i></sup> that is injective but not surjective.
