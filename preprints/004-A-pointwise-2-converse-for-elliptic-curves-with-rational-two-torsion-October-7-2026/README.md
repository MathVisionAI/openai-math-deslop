# A pointwise 2-converse for elliptic curves with rational two-torsion

Result 004 · Hilbert’s tenth problem over ℚ

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/ac881596-9dc0-4aa2-b157-55e7bcd39475) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-pointwise-2-converse-for-elliptic-curves-with-rational-two-torsion-October-7-2026/paper.pdf)

We prove a pointwise 2-converse for elliptic curves over $`\mathbf Q`$ with nonzero rational two-torsion: if the $`2^\infty`$-Selmer corank is zero or one, then the analytic rank and Mordell–Weil rank equal that corank, and the Shafarevich–Tate group is finite. The result allows arbitrary reduction at 2.
