# Additive hardness and unbounded configuration gaps in bin packing

Result 118 · Bin packing and unbounded configuration-LP gaps

We disprove the Modified Integer Round-Up Conjecture for bin packing by constructing instances with arbitrarily large additive gaps between the configuration-LP value and the integral optimum. We also prove that, for every fixed nonnegative integer <i>c</i>, distinguishing instances that fit in <i>B</i> bins from those requiring more than $`B+c`$ bins is NP-hard. Both results hold with rational item sizes greater than 1/6, so each bin contains at most five items.
