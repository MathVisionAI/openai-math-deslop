# Squarefree values of quartics and power-free values of polynomials

Result 020 · Squarefree quartics and power-free polynomial values

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/0b78820d-b5c8-4b13-ae49-a0f318f22fae) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Squarefree-values-of-quartics-and-power-free-values-of-polynomials-September-24-2026/manuscript.pdf)

We prove that every irreducible integer quartic with no fixed prime-square divisor takes squarefree values with the predicted positive Euler-product density. More generally, we obtain the corresponding $`(d-2)`$-power-free density in degrees $`4\le d\le8`$. The proof combines number-field factorization, determinant estimates with adaptive auxiliary primes, and explicit low-degree geometry. Together with Browning's theorem for higher degrees, this gives the $`(d-2)`$-power-free density for every <i>d</i> ≥ 4.
