# Routing densities and representation contraction for Thorp sweeps

Result 238 · Optimal logarithmic mixing of the Thorp shuffle

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/1d7ab643-a175-4827-9497-098a6d0bd3f0) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Routing-densities-and-representation-contraction-for-Thorp-sweeps-September-26-2026/paper.pdf)

For $`N=2^d`$ cards, we prove that an absolute number of coordinate sweeps of the Thorp shuffle brings the full permutation law to total-variation distance tending to zero from uniform. The mixing time therefore has optimal order $`\Theta(\log N)`$ in physical shuffles.
