# A PD4 group without an aspherical manifold model

Result 305 · Four-dimensional disk embedding and Wall's conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/217fdf9d-341a-4aae-8500-615fa2e72e47) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-PD4-group-without-an-aspherical-manifold-model-September-24-2026/paper.pdf)

We construct a finitely presented integral Poincaré duality group of dimension four that has a finite classifying space but is not the fundamental group of any closed aspherical topological four-manifold. This gives a negative answer to Wall's manifold-realization question in dimension four.
