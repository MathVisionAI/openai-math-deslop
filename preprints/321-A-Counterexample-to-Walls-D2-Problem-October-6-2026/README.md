# A Counterexample to Wall's D(2) Problem

Result 321 · A counterexample to Wall's finite D(2) problem

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/53e4fce7-8126-4b51-9ec5-492ccf8ab52b) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Counterexample-to-Walls-D2-Problem-October-6-2026/wall-d2-counterexample.pdf)

We give a negative answer to Wall's finite $`D(2)`$ problem. We construct a finite connected three-dimensional CW complex satisfying the $`D(2)`$ finiteness condition but not homotopy equivalent to any finite CW complex of dimension at most two. The example has infinite fundamental group.
