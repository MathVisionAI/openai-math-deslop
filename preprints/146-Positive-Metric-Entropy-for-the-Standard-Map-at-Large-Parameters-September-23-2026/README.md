# Positive Metric Entropy for the Standard Map at Large Parameters

Result 146 · Positive metric entropy for the standard map

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/bafe8f74-4f1b-4a4b-8484-5024c259dcb7) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Positive-Metric-Entropy-for-the-Standard-Map-at-Large-Parameters-September-23-2026/paper.pdf)

We prove that the standard sine map of the two-dimensional torus has positive metric entropy with respect to normalized area for every sufficiently large positive parameter. This gives a full parameter tail, and hence answers Sinai's positive-parameter-measure conjecture affirmatively.
