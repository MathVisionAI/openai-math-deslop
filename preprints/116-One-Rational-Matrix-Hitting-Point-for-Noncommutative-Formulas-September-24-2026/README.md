# One Rational Matrix Hitting Point for Noncommutative Formulas

Result 116 · Uniform black-box noncommutative identity testing across characteristics

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/7f68cbbd-9dca-4373-83ee-3ab6f8095794) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/One-Rational-Matrix-Hitting-Point-for-Noncommutative-Formulas-September-24-2026/One-Rational-Matrix-Hitting-Point-for-Noncommutative-Formulas-September-24-2026.pdf)

We construct, in deterministic polynomial bit time, one tuple of rational matrices that detects every nonzero polynomial computed by a noncommutative division-free formula of a prescribed size. The matrices have dimension $`O(ns^2)`$ for <i>n</i> variables and formula size <i>s</i>, and the same tuple works over every field of characteristic zero.
