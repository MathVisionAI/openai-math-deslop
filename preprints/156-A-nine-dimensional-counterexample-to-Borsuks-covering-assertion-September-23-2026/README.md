# A nine-dimensional counterexample to Borsuk's covering assertion

Result 156 · Borsuk's conjecture fails in dimension nine

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/62281c55-93c1-4aa8-82e5-4b4730c9fed7) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-nine-dimensional-counterexample-to-Borsuks-covering-assertion-September-23-2026/paper.pdf)

The compact set of rank-one orthogonal projectors on ℝ<sup>4</sup>, with the Frobenius metric, cannot be covered by ten sets of strictly smaller diameter. It therefore gives a counterexample to Borsuk's conjecture in dimension nine.
