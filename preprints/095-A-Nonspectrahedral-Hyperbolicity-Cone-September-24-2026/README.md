# A nonspectrahedral hyperbolicity cone

Result 095 · Hyperbolicity cones without semidefinite lifts

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/ccb73c0c-3aab-4fab-92b9-b9d977799b2a) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Nonspectrahedral-Hyperbolicity-Cone-September-24-2026/nonspectrahedral-hyperbolicity-cone.pdf)

We construct a homogeneous polynomial of degree 16 in 23 real variables whose hyperbolicity cone has no representation by a finite homogeneous real symmetric linear matrix inequality. This disproves the geometric Generalized Lax conjecture.
