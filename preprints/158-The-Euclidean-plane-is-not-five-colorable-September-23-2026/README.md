# The Euclidean plane is not five-colorable

Result 158 · The Euclidean plane cannot be colored with five colors

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/ae9d4680-55f0-4133-b586-29e8427519c0) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-Euclidean-plane-is-not-five-colorable-September-23-2026/paper.pdf)

We prove that every coloring of the Euclidean plane with five colors has a monochromatic unit-distance pair, with no regularity assumption on the color classes. Consequently, the chromatic number of the plane is either six or seven.
