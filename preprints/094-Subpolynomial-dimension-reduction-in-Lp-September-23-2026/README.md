# Subpolynomial dimension reduction in Lp

Result 094 · Subpolynomial dimension reduction in <i>L</i><sub><i>p</i></sub>

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/ffe3fbd7-f81d-487f-b095-2415dd0d03e7) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Subpolynomial-dimension-reduction-in-Lp-September-23-2026/paper.pdf)

For every fixed $`1\lt p\lt \infty`$ and <i>D</i> &gt; 1, every <i>n</i>-point subset of a real <i>L</i><sub><i>p</i></sub> space embeds into $`\ell_p^d`$ with distortion at most <i>D</i> and subpolynomial dimension $`d=n^{o(1)}`$. The target has the same exponent <i>p</i>, and the embedding need not be linear.
