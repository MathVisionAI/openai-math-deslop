# Translative covering densities of order n log n

Result 092 · The optimal order of convex-body covering density

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/f3118613-593b-4992-9845-517c2a3e8796) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Translative-covering-densities-of-order-n-log-n-September-23-2026/paper.pdf)

For every sufficiently large dimension <i>n</i>, we construct a centrally symmetric convex body whose translative covering density exceeds $`c n\log n`$, where <i>c</i> &gt; 0 is absolute. This disproves the existence of a universal linear upper bound and matches the order of Rogers' upper bound.
