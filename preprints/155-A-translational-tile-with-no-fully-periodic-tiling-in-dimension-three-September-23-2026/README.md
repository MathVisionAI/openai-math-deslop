# A translational tile with no fully periodic tiling in dimension three

Result 155 · A counterexample to periodic tiling in dimension three

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/d58725ca-af7e-43f7-88b6-64640b4a41dd) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-translational-tile-with-no-fully-periodic-tiling-in-dimension-three-September-23-2026/paper.pdf)

We construct a finite translational tile in ℤ<sup>3</sup> that admits tilings but no fully periodic tiling. Its unit-cube thickening has the same property in ℝ<sup>3</sup>, even when arbitrary real translations are allowed. This gives a negative resolution of the periodic tiling conjecture in dimension three.
