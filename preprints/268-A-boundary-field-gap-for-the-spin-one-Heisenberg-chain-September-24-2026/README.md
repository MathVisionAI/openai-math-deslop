# A boundary-field gap for the spin-one Heisenberg chain

Result 268 · The spin-one Haldane gap

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/06a63019-5391-4ebe-b20d-84d96bc95614) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-boundary-field-gap-for-the-spin-one-Heisenberg-chain-September-24-2026/paper.pdf)

We prove a uniform spectral gap for odd open spin-one antiferromagnetic Heisenberg chains with the same fixed magnetic field at both endpoints. The field $`h=3/5`$ gives a gap greater than $`\log(10)/392`$ on every chain of $`2L+1`$ sites with <i>L</i> ≥ 960. Tasaki's index theorem then gives index −1 for every subsequential local limit of these boundary-selected ground states.
