# A Modulus Proof of Cannon’s Conjecture

Result 246 · Cannon's conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/c609fb84-34ab-4d89-8e16-0b49819bf49b) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Modulus-Proof-of-Cannons-Conjecture-September-23-2026/paper.pdf)

We prove that every hyperbolic group whose boundary is homeomorphic to the two-sphere admits a proper cocompact isometric action on hyperbolic three-space with finite kernel. This resolves Cannon's conjecture positively.
