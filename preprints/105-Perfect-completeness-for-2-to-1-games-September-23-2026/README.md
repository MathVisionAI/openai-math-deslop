# Perfect completeness for 2-to-1 games

Result 105 · Perfect completeness for 2-to-1 games

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/76a07ef7-2b67-4c74-b4d8-74fecc11a7a6) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Perfect-completeness-for-2-to-1-games-September-23-2026/paper.pdf)

We prove the 2-to-1 Games Conjecture with perfect completeness. For every fixed rational $`\delta\in(0,1)`$, it is NP-hard to distinguish satisfiable 2-to-1 games from games of value at most <i>δ</i>, with a fixed alphabet and an explicitly listed unweighted multiset of constraints.
