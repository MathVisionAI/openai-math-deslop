# A linear list-coloring bound in terms of the Hadwiger number

Result 157 · Graph coloring, clique minors, and Colin de Verdière invariants

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/02d6bf0e-0109-45e8-8526-c2cfb9f2f09a) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-linear-list-coloring-bound-in-terms-of-the-Hadwiger-number-September-23-2026/paper.pdf)

We prove that every finite nonempty graph <i>G</i> satisfies $`\chi_{\mathrm{list}}(G)\le C h(G)`$ for an absolute integer <i>C</i>, where $`h(G)`$ is the largest order of a clique minor. This resolves the Linear List Hadwiger conjecture affirmatively.
