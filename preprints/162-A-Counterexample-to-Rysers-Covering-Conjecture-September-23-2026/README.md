# A counterexample to Ryser's covering conjecture

Result 162 · Counterexamples to Ryser’s covering conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/9086d654-8235-4e40-96bc-8c3af5d0fa49) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Counterexample-to-Rysers-Covering-Conjecture-September-23-2026/paper.pdf)

For every sufficiently large prime $`s\equiv2\pmod3`$ and every sufficiently large odd integer <i>n</i>, with the threshold depending on <i>s</i>, we construct an intersecting $`(s^n+1)`$-partite $`(s^n+1)`$-uniform hypergraph with covering number $`s^n+1`$. This disproves Ryser's covering conjecture in its intersecting case.
