# Simultaneous primitive roots: a conditional lower bound for prime bases

Result 029 · Primitive roots for every admissible integer base

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/0d98d723-4bdc-4261-9c13-d5868797a910) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Simultaneous-primitive-roots-a-conditional-lower-bound-for-prime-bases-October-4-2026/simultaneous-primitive-roots-conditional-lower-bound-prime-bases.pdf)

For every fixed finite set of distinct positive primes, we prove that at least $`cx/(\log x)^2`$ primes in $`(x,2x)`$ have every member of the set as a primitive root, for some <i>c</i> &gt; 0 and all sufficiently large <i>x</i>. The result assumes four explicitly stated analytic and sieve inputs from the companion paper on primitive roots for admissible integer bases.
