# A uniform influence bound for hypergraph properties

Result 186 · Uniform influence and sharp thresholds for graph and hypergraph properties

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/78a54667-760c-49af-aa92-bb8ac0cc9554) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-uniform-influence-bound-for-hypergraph-properties-October-5-2026/hypergraph-influences.pdf)

For every fixed integer <i>r</i> ≥ 3, we prove that every relabeling-invariant Boolean property of simple <i>r</i>-uniform hypergraphs on <i>n</i> vertices satisfies $`\mathop{\mathrm{Var}}\nolimits _p(f)\le C_r I_p(f)/(\log n)^{r/(r-1)}`$. The constant depends only on <i>r</i>, and the bound holds uniformly for all $`0\lt p\lt 1`$ without a monotonicity assumption. For increasing properties, it gives the corresponding threshold-width bound with exponent $`r/(r-1)`$, proving the hypergraph threshold-width conjecture of Friedgut and Kalai.
