# Virtual compact specialness of hyperbolic one-relator groups

Result 258 · Gersten’s conjecture and virtual compact specialness of one-relator groups

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/5a2e74ed-cc6f-453a-8149-c9a769bd4c6e) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Virtual-compact-specialness-of-hyperbolic-one-relator-groups-September-25-2026/paper.pdf)

We prove that every word-hyperbolic one-relator group is virtually compact special. Combined with the work of Kielak–Linton, this resolves Wise's virtual free-by-cyclic conjecture for hyperbolic one-relator groups: every such group is virtually free-by-cyclic, with the free kernel allowed to have infinite rank.
