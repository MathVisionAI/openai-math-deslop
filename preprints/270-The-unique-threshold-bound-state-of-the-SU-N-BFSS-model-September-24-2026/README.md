# The unique threshold bound state of the SU(N) BFSS model

Result 270 · Threshold and positive-energy bound states of the BFSS matrix model

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/f0542590-a3b4-4d4d-bb7a-65a59493f77d) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-unique-threshold-bound-state-of-the-SU-N-BFSS-model-September-24-2026/paper.pdf)

For every finite <i>N</i> ≥ 2, we prove that undeformed $`\mathop{\mathrm{SU}}\nolimits (N)`$ BFSS matrix quantum mechanics has exactly one normalizable zero-energy state after removing the center of mass. This establishes the threshold-bound-state conjecture.
