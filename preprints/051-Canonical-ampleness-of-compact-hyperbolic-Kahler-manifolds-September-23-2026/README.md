# Canonical ampleness of compact hyperbolic Kähler manifolds

Result 051 · Kobayashi’s canonical-ampleness conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/ca58941e-c7e8-49e7-af58-52fcf0b1ef05) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Canonical-ampleness-of-compact-hyperbolic-Kahler-manifolds-September-23-2026/canonical-ampleness.pdf)

We prove that every compact connected Kähler manifold of positive complex dimension containing no nonconstant entire curve has ample canonical bundle and is projective. This resolves positively Kobayashi's canonical-ampleness conjecture in the smooth compact Kähler category.
