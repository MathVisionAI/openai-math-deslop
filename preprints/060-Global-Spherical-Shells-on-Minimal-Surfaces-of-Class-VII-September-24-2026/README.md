# Global Spherical Shells on Minimal Surfaces of Class VII

Result 060 · The Global Spherical Shell conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/4076d543-dc9a-4f7f-a722-d7730059638b) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Global-Spherical-Shells-on-Minimal-Surfaces-of-Class-VII-September-24-2026/paper.pdf)

We prove the Global Spherical Shell conjecture: every connected minimal compact complex surface of class VII with positive second Betti number contains a global spherical shell. This is a holomorphically embedded neighborhood of the standard three-sphere in $`\mathbb C^2\setminus\{0\}`$ whose complement is connected.
