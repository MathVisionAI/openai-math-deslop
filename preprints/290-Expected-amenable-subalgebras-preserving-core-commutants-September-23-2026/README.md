# Expected amenable subalgebras preserving core commutants

Result 290 · Relative bicentralizers and modular spectral recovery

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/8adc2eb9-3600-4082-b648-96cd37cb03e8) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Expected-amenable-subalgebras-preserving-core-commutants-September-23-2026/Expected-amenable-subalgebras-preserving-core-commutants-September-23-2026.pdf)

We prove that every inclusion $`N\subset M`$ of von Neumann algebras with separable preduals and a faithful normal conditional expectation contains an expected amenable subalgebra $`P\subset N`$ such that $`P'\cap c(M)=N'\cap c(M)`$, where $`c(M)`$ denotes the continuous core of <i>M</i>. This resolves the relative bicentralizer conjecture in this setting.
