# A quadratic bound for Jacobsthal's function

Result 021 · A quadratic bound for Jacobsthal’s function

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/2e1d491a-4cc5-4e0c-be5d-3eac110079ff) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-quadratic-bound-for-Jacobsthals-function-September-25-2026/paper.pdf)

Let $`h(k)`$ be the least integer such that every interval of $`h(k)`$ consecutive integers contains an integer coprime to any prescribed positive integer having at most <i>k</i> distinct prime divisors. We prove $`h(k)\ll k^2/(\log\log(3k))^2`$, giving an affirmative answer to Jacobsthal's quadratic-bound question.
