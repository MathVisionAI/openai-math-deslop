# Uniform Cartier sections for Fano type contractions

Result 066 · Bounded klt complements for Fano contractions

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/5726e157-2083-4d72-96b4-c7f7b4cfd179) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Uniform-Cartier-sections-for-Fano-type-contractions-September-25-2026/Uniform-Cartier-sections-for-Fano-type-contractions-September-25-2026.pdf)

We prove the Cartier-divisor conjecture of Birkar and Shokurov for rational boundaries in characteristic zero and for real boundaries over ℂ. For an <i>ϵ</i>-lc Fano type contraction with positive-dimensional base and nef negative log canonical class, a Cartier divisor through any prescribed base point can be chosen with pullback log canonical threshold bounded below in terms of the dimension and <i>ϵ</i> alone.
