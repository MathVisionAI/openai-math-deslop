# The geometric case of the Erdős similarity conjecture

Result 084 · The geometric case of the Erdős similarity conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/567aeaa0-8354-4714-b380-52a863e9c557) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-geometric-case-of-the-Erdos-similarity-conjecture-October-5-2026/geometric-erdos-similarity.pdf)

We prove the geometric-progression case of the Erdős similarity conjecture. For every fixed $`q\in(0,1)`$ and every $`\eta\in(0,1)`$, we construct a compact set $`E_{q,\eta}\subseteq[0,1]`$ of measure greater than $`1-\eta`$ containing no nontrivial affine copy of $`\{q^n:n\ge1\}`$, for any translation and either sign of nonzero dilation. The set may depend on <i>q</i>; the result makes no simultaneous assertion for different ratios.
