# A Torsion-Free Group Algebra with Zero Divisors

Result 196 · A counterexample to Kaplansky’s zero-divisor conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/6f7b2cb5-8c34-453f-980a-ce2b884e42e8) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Torsion-Free-Group-Algebra-with-Zero-Divisors-September-23-2026/paper.pdf)

We disprove Kaplansky's zero-divisor conjecture by constructing a finitely presented torsion-free group <i>G</i> for which $`\mathbb F_2[G]`$ has nonzero zero divisors. The group admits a finite two-dimensional classifying space.
