# Kadison's similarity theorem through uniform derivation estimates

Result 288 · Kadison's similarity conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/41421150-a076-443b-a5b9-a730c7ef5e8c) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Kadisons-similarity-theorem-through-uniform-derivation-estimates-September-23-2026/paper.pdf)

We prove that every bounded complex-linear unital algebra homomorphism from a unital complex <i>C</i><sup>∗</sup>-algebra into the bounded operators on an arbitrary Hilbert space is similar to a $`*`$-homomorphism. This resolves Kadison's similarity conjecture positively. We also obtain one universal hyperreflexivity constant for all unital von Neumann algebras on arbitrary complex Hilbert spaces.
