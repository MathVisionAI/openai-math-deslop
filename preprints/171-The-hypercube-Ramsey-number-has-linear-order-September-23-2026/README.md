# The hypercube Ramsey number has linear order

Result 171 · The hypercube Ramsey conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/095e3157-80d2-47bf-aad2-486fa98efab4) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-hypercube-Ramsey-number-has-linear-order-September-23-2026/paper.pdf)

We prove that the two-color Ramsey number of the <i>n</i>-dimensional binary cube is at most $`C2^n`$, where <i>C</i> is an absolute constant. This resolves positively the hypercube Ramsey conjecture of Burr and Erdős.
