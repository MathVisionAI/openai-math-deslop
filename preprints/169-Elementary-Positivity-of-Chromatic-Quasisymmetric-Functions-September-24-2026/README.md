# Elementary positivity of chromatic quasisymmetric functions

Result 169 · Shareshian–Wachs elementary positivity

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/8c969fab-4c26-47e4-9791-b1bd9be8398a) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Elementary-Positivity-of-Chromatic-Quasisymmetric-Functions-September-24-2026/paper.pdf)

We prove that the chromatic quasisymmetric function of every natural unit interval graph is elementary-positive over $`\mathbb N[q]`$. This resolves the elementary-positivity part of the Shareshian–Wachs conjecture.
