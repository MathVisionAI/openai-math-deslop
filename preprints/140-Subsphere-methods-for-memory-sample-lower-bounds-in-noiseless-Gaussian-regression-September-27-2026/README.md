# Subsphere methods for memory-sample lower bounds in noiseless Gaussian regression

Result 140 · Memory–sample lower bounds for noiseless Gaussian regression

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/4bc8e651-b3ed-48ed-acb5-531327103379) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Subsphere-methods-for-memory-sample-lower-bounds-in-noiseless-Gaussian-regression-September-27-2026/paper.pdf)

Let a finite-state streaming learner estimate a uniformly random unit vector from independent exact Gaussian linear measurements. We prove that $`o(d^2)`$ bits of persistent memory and angular success probability at least 2/3 require at least $`2^{-16}d\log_2(1/\epsilon)`$ samples for all sufficiently large <i>d</i>, uniformly for $`0\lt \epsilon\le1/10`$. The proof conditions each batch on its observed projection and controls the resulting random residual subsphere.
