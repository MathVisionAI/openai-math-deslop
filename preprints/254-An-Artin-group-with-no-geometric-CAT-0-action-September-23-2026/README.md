# An Artin group with no geometric CAT(0) action

Result 254 · Classifying spaces and geometric obstructions for Artin groups

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/2801dd93-927f-4dc6-b560-5b27ed08ef84) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/An-Artin-group-with-no-geometric-CAT-0-action-September-23-2026/paper.pdf)

We construct an Artin group on 116 generators that admits no proper, cocompact isometric action on a nonempty proper CAT(0) space. This refutes the CAT(0) conjecture for Artin groups.
