# The sharp factor-of-IID threshold for the free Ising model on regular trees

Result 236 · The exact factor-of-IID threshold for free Ising spins on trees

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/d3f3c975-d0fc-4a05-b7d8-aee8257ce7eb) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-sharp-factor-of-IID-threshold-for-the-free-Ising-model-on-regular-trees-September-26-2026/article.pdf)

For every integer <i>d</i> ≥ 3 and inverse temperature <i>β</i> ≥ 0, the free zero-field ferromagnetic Ising measure on the infinite <i>d</i>-regular tree is a factor of IID exactly when $`\tanh\beta\le(d-1)^{-1/2}`$. We prove the positive implication, including equality, resolving the conjecture of Nam, Sly and Zhang; the strict converse is known. The spin factor can be chosen to commute with every tree automorphism on every label input.
