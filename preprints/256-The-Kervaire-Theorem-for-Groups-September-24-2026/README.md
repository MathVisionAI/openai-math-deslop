# The Kervaire theorem for groups

Result 256 · Nonsingular systems of equations over arbitrary groups

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/aa8ac83f-6001-4e97-a16c-5c8229700569) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-Kervaire-Theorem-for-Groups-September-24-2026/The-Kervaire-Theorem-for-Groups-September-24-2026.pdf)

We prove that no free product of a nontrivial group with an infinite cyclic group is normally generated by one element. This resolves the Kervaire conjecture positively.
