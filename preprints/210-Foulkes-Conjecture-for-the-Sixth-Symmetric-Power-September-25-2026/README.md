# Foulkes' conjecture for the sixth symmetric power

Result 210 · Foulkes' conjecture for sixth powers and quadratic stabilization

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/54bd0553-19b2-4007-99f8-2e9d970ed195) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Foulkes-Conjecture-for-the-Sixth-Symmetric-Power-September-25-2026/main.pdf)

We prove the sixth-symmetric-power case of Foulkes' conjecture. For every integer <i>b</i> ≥ 6 and every finite-dimensional complex vector space <i>V</i>, there is a $`\mathop{\mathrm{GL}}\nolimits (V)`$-equivariant injection $`\mathop{\mathrm{Sym}}\nolimits ^6(\mathop{\mathrm{Sym}}\nolimits ^b V)\hookrightarrow\mathop{\mathrm{Sym}}\nolimits ^b(\mathop{\mathrm{Sym}}\nolimits ^6 V)`$.
