# The metric Blaschke theorem

Result 344 · The metric Blaschke conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/bd62fc0d-74e8-49b5-9160-0aa6764ee854) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-metric-Blaschke-theorem-September-23-2026/paper.pdf)

We prove the metric Blaschke conjecture: every connected closed smooth Riemannian manifold of positive dimension whose global injectivity radius equals its diameter is, up to scale, a standard compact rank-one symmetric space.
