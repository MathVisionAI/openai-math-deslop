# Continuous Phase Foliations Create Analytic Caustic Collars

Result 147 · The near-boundary Birkhoff conjecture

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/9d3b8e32-1757-4fc6-ab78-ec064241361c) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Continuous-Phase-Foliations-Create-Analytic-Caustic-Collars-September-24-2026/paper.pdf)

For a smooth strictly convex planar billiard of positive curvature, a continuous foliation of a full grazing annulus by individually invariant essential curves forces an analytic boundary and a jointly analytic collar of smooth strictly convex caustics. The physical-collar rigidity theorem proved in the companion article then implies that the table is an ellipse.
