# Planar Graph Metrics Embed into L1 with Constant Distortion

Result 089 · Bounded-distortion <i>L</i><sub>1</sub> embeddings of planar and bounded-treewidth graphs

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/fb4d14f7-c7d0-49ea-afcc-6fe4f08b3655) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Planar-Graph-Metrics-Embed-into-L1-with-Constant-Distortion-September-23-2026/paper.pdf)

We prove that every finite connected planar graph with arbitrary positive real edge lengths embeds into real <i>L</i><sub>1</sub> with a universal distortion bound. This resolves the planar embedding conjecture positively.
