# A negative solution to the finite lattice representation problem

Result 206 · Finite lattice representation and undecidability

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/7a94777b-17d6-4d47-901b-488f9d93414a) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Negative-Solution-to-the-Finite-Lattice-Representation-Problem-September-24-2026/paper.pdf)

We give a negative solution to the finite lattice representation problem. We prove that there is a finite nonempty lattice that is not the full congruence lattice of any finite nonempty algebra of any finite signature.
