# Bounded recovery for modular spectral averages

Result 290 · Relative bicentralizers and modular spectral recovery

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/37dd99d1-41b6-4704-ac76-e9f0f152ed92) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Bounded-recovery-for-modular-spectral-averages-September-23-2026/Bounded-recovery-for-modular-spectral-averages-September-23-2026.pdf)

We prove a bounded spectral recovery theorem for a von Neumann algebra with a faithful normal state whose centralizer consists only of scalars. A positive averaged squared norm for an arbitrary bounded Hilbert-space operator on shrinking modular spectral bands can be recovered on uniformly bounded algebra elements with shrinking spectral support. We apply this theorem to spectral intertwining rigidity and obtain an alternative proof of bicentralizer triviality for type III<sub>1</sub> factors with separable predual.
