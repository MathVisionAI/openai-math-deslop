# Donovan's Conjecture over Algebraically Closed Fields

Result 203 · Donovan's conjecture over fields and complete mixed-characteristic DVRs

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/36bf8bd6-e0ca-4033-8210-42fd0e89accb) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Donovans-Conjecture-over-Algebraic-Closures-of-Prime-Fields-September-24-2026/main.pdf)

We prove Donovan's conjecture over every algebraically closed field <i>K</i> of characteristic <i>p</i> &gt; 0. For each fixed <i>K</i> and bound on defect-group order, blocks of finite groups represent only finitely many <i>K</i>-linear Morita equivalence classes. The defect groups need not be abelian, and the result includes <i>p</i> = 2.
