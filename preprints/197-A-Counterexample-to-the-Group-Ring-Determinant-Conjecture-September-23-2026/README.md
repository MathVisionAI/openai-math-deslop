# A Counterexample to the Group-Ring Determinant Conjecture

Result 197 · A torsion-free group algebra that is not directly finite

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e2bd000f-dbae-4f3b-80e0-abfe86b0ed1a) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/A-Counterexample-to-the-Group-Ring-Determinant-Conjecture-September-23-2026/paper.pdf)

We disprove the unrestricted group-ring Determinant Conjecture. We construct a finitely generated group <i>G</i> and a square matrix over $`\mathbb Z[G]`$ that is invertible over $`\mathbb Q[G]`$ and has Fuglede–Kadison determinant strictly between zero and one. The logarithmic integral defining the determinant is finite.
