# The circulant Hadamard conjecture

Result 179 · The circulant Hadamard and Barker-sequence conjectures

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/33220aba-6059-4625-8653-048121058b75) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-circulant-Hadamard-conjecture-September-23-2026/paper.pdf)

We prove the circulant Hadamard conjecture: a real circulant Hadamard matrix has order 1 or 4. As a consequence, Barker sequences of length greater than one exist exactly at lengths 2, 3, 4, 5, 7, 11, 13, proving the Barker-sequence conjecture.
