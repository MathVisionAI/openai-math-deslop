# Memory and precision in noiseless Gaussian regression

Result 140 · Memory–sample lower bounds for noiseless Gaussian regression

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/25454d48-2bf9-424b-b629-eb231a0a3e4b) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Memory-and-precision-in-noiseless-Gaussian-regression-September-27-2026/paper.pdf)

For every fixed <i>A</i> &gt; 0, a learner that retains at most $`Ad^2`$ bits between fresh exact Gaussian linear measurements needs $`\Omega_A(d\log(1/\epsilon))`$ measurements to estimate a uniformly random unit vector to angular error at most <i>ϵ</i>, for any $`0\lt \epsilon\le 1/10`$, with probability at least 2/3. The constant is absolute for $`o(d^2)`$ memory.
