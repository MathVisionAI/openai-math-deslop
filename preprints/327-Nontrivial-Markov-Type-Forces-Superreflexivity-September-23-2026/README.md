# Nontrivial Markov Type Forces Superreflexivity

Result 327 · Markov type characterizes superreflexivity

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/9eac9c92-4775-4f39-96bb-7bf74f2c73f9) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Nontrivial-Markov-Type-Forces-Superreflexivity-September-23-2026/paper.pdf)

We prove that every real Banach space with Markov type <i>p</i> &gt; 1 is superreflexive. Together with the known converse, this characterizes superreflexivity by nontrivial Markov type. This answers Naor's question: every real Banach space with nontrivial Markov type admits an equivalent uniformly smooth norm.
