# Primitive roots for every admissible integer base

Result 029 · Primitive roots for every admissible integer base

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/e2ef8f8f-a54d-44eb-9564-8e5775b1fb2d) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Primitive-roots-for-every-admissible-integer-base-October-4-2026/primitive-roots-all-integer-bases.pdf)

We prove the infinitude assertion in Artin's primitive root conjecture: for every integer <i>a</i> that is neither −1 nor a square, there are at least $`c_a x/(\log x)^2`$ primes in $`(x,2x)`$ with primitive root <i>a</i>, for some $`c_a\gt 0`$ and every sufficiently large <i>x</i>.
