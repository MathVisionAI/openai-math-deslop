# Brennan's conjecture and sharp inverse-square integral means

Result 072 · Brennan's conjecture and the integral-means spectrum

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/f3e12f62-151c-46b2-984b-000206d890a2) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Brennans-conjecture-and-sharp-inverse-square-integral-means-September-24-2026/paper.pdf)

We prove Brennan's conjecture: if a simply connected plane domain admits a conformal bijection <i>φ</i> onto the unit disk, then $`|\varphi'|^s`$ is area-integrable for every $`4/3\lt s\lt 4`$. We also prove the sharp inverse-square integral-means exponent $`B_{\mathcal S}(-2)=1`$ for the normalized schlicht class $`\mathcal S`$.
