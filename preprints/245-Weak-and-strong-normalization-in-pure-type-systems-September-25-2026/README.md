# Weak and strong normalization in pure type systems

Result 245 · Weak normalization implies strong normalization in pure type systems

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/b6ff045d-1876-40c5-b4ee-fdf0a0f0338e) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Weak-and-strong-normalization-in-pure-type-systems-September-25-2026/paper.pdf)

We prove that every weakly <i>β</i>-normalizing pure type system is strongly <i>β</i>-normalizing. Both properties quantify over all legal expressions in all valid contexts, and reduction acts inside type annotations. No functionality hypothesis is required. This resolves the <i>β</i>-Barendregt–Geuvers–Klop conjecture.
