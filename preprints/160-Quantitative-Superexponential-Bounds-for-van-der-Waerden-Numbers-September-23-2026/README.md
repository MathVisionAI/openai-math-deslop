# Quantitative Superexponential Bounds for van der Waerden Numbers

Result 160 · Superexponential van der Waerden numbers

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/3bcac518-4b1a-40d1-8646-4b64b2bc8fb4) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Quantitative-Superexponential-Bounds-for-van-der-Waerden-Numbers-September-23-2026/paper.pdf)

We prove that there are absolute constants <i>c</i> &gt; 0 and <i>K</i><sub>0</sub> such that $`W_r(k)\gt k^{ck\lfloor\log_2 r\rfloor}`$ for every $`k\ge K_0`$ and <i>r</i> ≥ 2. Consequently $`W_r(k)^{1/k}\to\infty`$ for each fixed <i>r</i> ≥ 2, giving a quantitative positive resolution of Erdős's superexponential-growth question, including the two-color case.
