# Unitarizability implies amenability for discrete groups

Result 251 · Amenability, unitarizability, and strong Ulam stability

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/b70941f2-7d88-42ca-a1c7-7e3385642163) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Unitarizability-Implies-Amenability-for-Countable-Groups-September-23-2026/paper.pdf)

We prove that a discrete group is amenable if and only if every uniformly bounded representation on a complex Hilbert space is similar to a unitary representation. This resolves Dixmier's unitarizability problem affirmatively for discrete groups.
