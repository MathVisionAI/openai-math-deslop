# Global Uniqueness for the Smooth Isotropic Elasticity Inverse Problem

Result 372 · Global uniqueness in smooth isotropic elasticity

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/c108c493-46ac-42a7-ab3e-3ae571000351) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Global-Uniqueness-for-the-Smooth-Isotropic-Elasticity-Inverse-Problem-September-24-2026/article.pdf)

We prove that the full static displacement-to-traction map uniquely determines both real smooth Lamé moduli on every bounded connected smooth domain in ℝ<sup>3</sup>, provided <i>μ</i> &gt; 0 and $`3\lambda+2\mu\gt 0`$ on the closure. This resolves the smooth three-dimensional isotropic elastic Calderón uniqueness problem under these positivity assumptions.
