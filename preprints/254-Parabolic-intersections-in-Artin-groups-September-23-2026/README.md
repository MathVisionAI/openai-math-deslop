# Parabolic intersections in Artin groups

Result 254 · Classifying spaces and geometric obstructions for Artin groups

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/48aa0cd2-7afa-412a-9358-5e89c3ffcbf4) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/Parabolic-intersections-in-Artin-groups-September-23-2026/paper.pdf)

We prove that every intersection of parabolic subgroups of any finite-rank Artin group, with arbitrary finite or infinite Coxeter labels, is parabolic. This resolves the Parabolic Intersection Conjecture affirmatively.
