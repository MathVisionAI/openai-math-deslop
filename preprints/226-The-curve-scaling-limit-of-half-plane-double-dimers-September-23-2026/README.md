# The curve scaling limit of half-plane double dimers

Result 226 · The double-dimer loop ensemble converges to CLE<sub>4</sub>

[Read in MathVision Reading Mode](https://app.mathvision.ai/share/pdfs/d2f10076-1b24-491d-a494-4df46403ff0e) · [Original PDF](https://github.com/openai/math/blob/1581d4cbdd69a0faf34b2089614fe2a814316a6a/preprints/The-curve-scaling-limit-of-half-plane-double-dimers-September-23-2026/paper.pdf)

We prove that the complete double-dimer loop ensemble for the Temperleyan square lattice in the upper half-plane converges to nested CLE<sub>4</sub>. The convergence holds along the full mesh limit and matches every macroscopic loop as an unparametrized curve. This resolves the half-plane Temperleyan form of the double-dimer CLE<sub>4</sub> scaling-limit conjecture.
