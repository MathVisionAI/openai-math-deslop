# Enhanced Versions of OpenAI's Mathematics PDFs

This repository contains enhanced version of [OpenAI's mathematical manuscripts](https://github.com/openai/math), processed through [MathVision's](https://mathvision.ai) Reading Mode to improve readability and make the results easier to examine.

### What's included

- Hyperlinks to enhanced PDFs designed for improved readability.
- Support for text annotations, comments, and attachments.
- Interactive AI assistance for explaining passages, clarifying notation, and finding relevant references.

Annotations and interactive features require a free MathVision account.

### Notes

- These manuscripts have not been independently verified by MathVision
- AI-generated mathematical arguments require careful human review. Our goal is to facilitate that review.
- Original manuscripts are available in [OpenAI's repository](https://github.com/openai/math). Please cite the original sources.

Issues and contributions are welcome, particularly suggestions for improving readability.
